### Open source

- [**Boite**](https://github.com/mtsu-dev/boite) - Desktop workspace for coding agents (Claude Code, Codex, OpenCode and more), also driven from your phone. [boite.mtsu.dev](https://boite.mtsu.dev)
- [**Douane**](https://github.com/mtsu-dev/douane) - Self-hosted gateway that serves your AI subscriptions to any coding tool, with quota-aware routing and a dashboard.
- [**fastpick**](https://github.com/mtsu-dev/fastpick) - Terminal picker for coding agents: harness, provider, model and system prompt, then launch. On [crates.io](https://crates.io/crates/fastpick).
